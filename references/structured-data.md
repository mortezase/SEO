# Structured data

Use structured data to describe visible, truthful page content. It does not guarantee a rich result.

Prefer JSON-LD unless the platform requires another supported format. Select types supported by the search platform and appropriate to the page, then include required and useful recommended properties.

Connect entities consistently using stable `@id` values where helpful. Keep organization, website, webpage, breadcrumb, article, product, offer, local business, person, event, video, and other objects aligned with visible content and canonical URLs.

Never mark up hidden, misleading, fabricated, user-invisible, or prohibited content. Do not create fake ratings, reviews, prices, availability, authors, jobs, events, or FAQs.

Validate syntax, vocabulary, platform eligibility, URL resolution, dates, currencies, availability, image accessibility, and consistency with rendered content. Revalidate after template changes.
