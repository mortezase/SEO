# SEO Agent Skill

An evidence-based SEO skill for Claude Code, Codex, ChatGPT, Cursor, and other Agent Skills-compatible tools.

It covers technical SEO, keyword and content strategy, structured data, local/international/ecommerce SEO, internal links and authority, GEO/AEO, measurement, implementation, and quality assurance.

## Install

Clone the repository into the skill directory used by your agent, or install it with an Agent Skills-compatible installer. The repository root is the skill folder and contains `SKILL.md`.

Example for Claude Code:

```bash
git clone https://github.com/mortezase/SEO.git ~/.claude/skills/seo
```

Example request:

```text
Use the SEO skill to audit this site, prioritize the findings, implement safe code fixes, and explain how to validate the results.
```

The skill does not invent keyword volumes, traffic, rankings, backlinks, citations, or competitor results. Connect or provide first-party and third-party data when those measurements are required.
